# Beauty Parlour website

Folder layout:
  index.html   the whole site
  images/      her photos (see images/README.txt)

Before going live, open index.html and edit CONFIG near the bottom:
  whatsapp   her number, country code first, no + (e.g. 254712345678)
  instagram  her Instagram link (optional)
Also update the prices and opening hours in the text.

Deploy on Netlify: drag this whole folder onto https://app.netlify.com/drop
